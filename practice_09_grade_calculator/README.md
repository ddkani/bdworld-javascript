# Practice 09: 가중평균 성적 계산기

## 개요
다양한 과목/과제를 처리하고 설정 가능한 가중치와 상세한 성적 분석을 제공하는 종합적인 성적 계산기를 구축합니다.

## 요구사항

### 핵심 기능
1. **성적 입력 관리**
   - 다양한 과목/과제에 대한 성적 추가
   - 점수 입력 (0-100) 또는 문자 성적 (A-F)
   - 기존 성적 항목 편집 및 삭제
   - 일괄 가져오기/내보내기 기능

2. **가중치 설정**
   - 각 성적 항목에 사용자 정의 가중치 할당
   - 백분율 기반 가중치 시스템
   - 자동 가중치 검증 및 정규화
   - 미리 설정된 가중치 템플릿 (균등, 시험 중심, 숙제 중심)

3. **가중평균 계산**
   - 할당된 가중치를 기반으로 한 가중평균 계산
   - 누락된 성적 적절히 처리
   - 실시간 계산 업데이트
   - 계산 세부사항 표시

4. **성적 문자 변환**
   - 숫자 성적을 문자 성적으로 변환 (A, B, C, D, F)
   - 설정 가능한 성적 척도
   - 플러스/마이너스 성적 지원 (A+, A-, B+ 등)
   - GPA 계산 (4.0 척도)

### 고급 기능
- 성적 동향 및 진도 추적
- 카테고리 그룹화 (시험, 숙제, 프로젝트 등)
- 목표 설정 및 "가정 상황" 시나리오
- 성적 통계 (최소, 최대, 평균, 표준편차)
- 시각적 성적 분포 차트
- PDF/CSV 내보내기 기능

### 기술적 구현
- 성적 계산을 위한 배열 메서드 사용
- 성적 입력을 위한 폼 검증 구현
- 성적 항목을 위한 동적 DOM 요소 생성
- 데이터 지속성을 위한 localStorage 사용
- 적절한 반올림을 통한 수학적 계산 구현
