# Practice 08: 쇼핑카트 애플리케이션

## 개요
상품 목록, 카트 관리, 그리고 localStorage를 이용한 지속적 저장 기능이 있는 완전한 쇼핑카트 애플리케이션을 구축합니다.

## 요구사항

### 핵심 기능
1. **상품 목록 표시**
   - 이미지, 이름, 가격, 설명이 포함된 상품 표시
   - 반응형 디자인의 그리드 레이아웃
   - 각 상품별 "카트에 담기" 버튼
   - 재고 수량 표시

2. **카트 관리**
   - 상품을 카트에 추가
   - 카트에서 개별 상품 제거
   - 상품 수량 업데이트 (증가/감소)
   - 전체 카트 비우기 기능

3. **가격 계산**
   - 개별 상품 총액 (가격 × 수량)
   - 소계 계산
   - 세금 계산 (설정 가능한 세율)
   - 세금 포함 최종 총액

4. **LocalStorage 지속성**
   - 카트 상태를 localStorage에 저장
   - 페이지 새로고침 시 카트 복원
   - 저장 공간 한계 처리
   - 저장소 비우기 옵션

### 고급 기능
- 상품 검색 및 필터링
- 헤더의 카트 상품 개수 표시
- 애니메이션 카트 업데이트
- 상품 카테고리
- 할인 코드 지원
- 주문 요약 모달

### 기술적 구현
- 카트 작업을 위한 배열 메서드 사용
- 동적 요소를 위한 이벤트 위임 구현
- 카트 계산을 위한 재사용 가능한 함수 생성
- localStorage 직렬화를 위한 JSON 사용
- 조직화를 위한 MVC 유사 패턴 구현

## JavaScript 과정 참조

### 1-2주차: JavaScript 기초
- 상품 데이터와 카트 상태를 위한 변수
- 카트 작업(추가, 제거, 업데이트)을 위한 함수
- 카트 로직과 검증을 위한 조건문
- 가격 계산을 위한 수학 연산

### 3-4주차: DOM 조작
- 동적 콘텐츠를 위한 `document.createElement()`
- 업데이트를 위한 `innerHTML`과 `textContent`
- 버튼과 상호작용을 위한 이벤트 리스너
- 시각적 피드백을 위한 클래스 조작

### 5-6주차: 고급 함수 & 배열
- 배열 메서드: `find()`, `filter()`, `map()`, `reduce()`
- 카트 작업을 위한 고차 함수
- 더 깔끔한 코드를 위한 배열 구조분해
- 상태 업데이트를 위한 스프레드 연산자

### 7-8주차: 객체 & 고급 개념
- 객체 지향 카트 관리
- 지속성을 위한 LocalStorage API
- JSON 직렬화 및 파싱
- 저장소 작업을 위한 에러 처리
