# Practice 07: 비밀번호 검증기

## 개요
실시간 피드백과 비밀번호 보안을 위한 시각적 표시기를 제공하는 종합적인 비밀번호 강도 검증기를 구축합니다.

## 요구사항

### 핵심 기능
1. **비밀번호 요구사항 검증**
   - 최소 8자 이상
   - 최소 1개의 대문자 (A-Z)
   - 최소 1개의 소문자 (a-z)
   - 최소 1개의 숫자 (0-9)
   - 최소 1개의 특수문자 (!@#$%^&*)

2. **실시간 검증 피드백**
   - 사용자가 입력할 때마다 실시간 검증
   - 개별 요구사항 표시기 (체크마크/X표시)
   - 색상 코드 피드백 (빨강/노랑/초록)

3. **강도 측정기 시각화**
   - 비밀번호 강도를 보여주는 진행 바
   - 강도 레벨: 매우 약함, 약함, 보통, 좋음, 강함
   - 강도에 따른 동적 색상 변화

4. **비밀번호 가시성 토글**
   - 비밀번호 보이기/숨기기 버튼
   - 상태에 따라 변하는 눈 아이콘
   - 토글 시 커서 위치 유지

### 기술적 구현
- 실시간 검증을 위한 입력 이벤트 리스너 사용
- 다양한 문자 유형을 위한 정규식 패턴 구현
- 피드백을 위한 동적 DOM 조작 생성
- 시각적 상태 변화를 위한 CSS 클래스 사용
- 강도 계산 알고리즘 구현

## JavaScript 과정 참조

### 1-2주차: JavaScript 기초
- 검증 상태를 저장하기 위한 변수와 데이터 타입
- 모듈식 검증 로직을 위한 함수
- 요구사항 확인을 위한 조건문

### 3-4주차: DOM 조작
- 요소 선택을 위한 `document.querySelector()`
- 입력 이벤트를 위한 `addEventListener()`
- `classList`를 이용한 동적 클래스 조작
- 피드백 메시지를 위한 텍스트 콘텐츠 업데이트

### 5-6주차: 고급 함수 & 배열
- 요구사항 확인을 위한 배열 메서드
- 검증 로직을 위한 함수 합성
- 패턴 매칭을 위한 정규 표현식

### 7-8주차: 객체 & 고급 개념
- 검증기를 위한 객체 지향 접근법
- 요구사항을 위한 설정 객체
- 검증 확인을 위한 메서드 체이닝
