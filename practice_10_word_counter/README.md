# Practice 10: 단어 카운터 & 텍스트 분석 도구

## 개요
작성된 콘텐츠에 대한 상세한 통계를 제공하는 종합적인 텍스트 분석 도구를 구축합니다. 단어 수, 문자 분석, 가독성 지표, 글쓰기 인사이트를 포함합니다.

## 요구사항

### 핵심 기능
1. **기본 텍스트 계수**
   - 단어 수 (다양한 단어 정의 포함)
   - 문자 수 (공백 포함 및 제외)
   - 문장 수
   - 단락 수
   - 행 수

2. **고급 분석**
   - 문장당 평균 단어 수
   - 단어당 평균 문자 수
   - 최빈 단어 (사용자 정의 불용어 포함)
   - 가장 긴 단어와 가장 짧은 단어
   - 고유 단어 수

3. **읽기 시간 추정**
   - 읽기 시간 계산 (평균 분당 200단어)
   - 말하기 시간 계산 (평균 분당 150단어)
   - 설정 가능한 읽기 속도 설정
   - 다양한 연령대별 시간

4. **글쓰기 통계**
   - 가독성 지표 (Flesch 읽기 용이성 등)
   - 학년 수준 추정
   - 어휘 복잡도 분석
   - 문장 구조 분석

### 고급 기능
- 사용자가 입력할 때 실시간 분석
- 텍스트 내보내기 기능 (순수 텍스트, 통계 보고서)
- 단어 빈도 시각화
- 텍스트 비교 도구
- 글쓰기 목표 및 진행 상황 추적
- 언어 감지
- 키워드 밀도 분석

### 기술적 구현
- 텍스트 파싱을 위한 정규 표현식 사용
- 성능을 위한 디바운스 입력 구현
- 재사용 가능한 유틸리티 함수 생성
- 빈도 분석을 위한 데이터 구조 사용
- 통계 계산 구현

## JavaScript 과정 참조

### 1-2주차: JavaScript 기초
- 텍스트 통계를 저장하기 위한 변수
- 계수 및 계산을 위한 함수
- 텍스트 검증을 위한 조건문

### 3-4주차: DOM 조작

- 통계 표시의 동적 업데이트

- 입력 변경을 위한 이벤트 리스너

### 5-6주차: 고급 함수 & 배열
- 텍스트 처리를 위한 배열 메서드: `split()`, `filter()`, `map()`, `reduce()`
- 문자열 메서드: `match()`, `replace()`, `trim()`
- 패턴 매칭을 위한 정규 표현식
- 데이터 변환을 위한 고차 함수

### 7-8주차: 객체 & 고급 개념
- 객체 지향 텍스트 분석
- 단어 빈도를 위한 복잡한 데이터 구조
- 성능 최적화 기법
- 고급 문자열 조작 알고리즘
